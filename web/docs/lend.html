Lend your AI

Help an open-source project with your own AI subscription.

All you need is Claude, on any plan. No GitHub account, no coding, nothing to install.

1. Add the connector (one time)

  1. In Claude, open Settings → Connectors.
  2. Click + → Add custom connector and paste https://lendmyai.com/mcp.
  3. Click Connect and choose the name you want to be credited with.

2. Pick a task

On lendmyai.com, open the Projects page. You can search it, filter by language and by projects with open tasks, and sort the list. Pick a task, click Open Claude, then press Send.

3. Claude does the work

Claude reads the project, makes the changes, and sends them to the owner. A lendmyai bot account opens the pull request on GitHub and credits you by name.

With GitHub: Claude Code in the cloud

If you have GitHub and Claude Pro or Max, sign in on lendmyai.com and use Start with Claude Code (cloud) on a task. Claude Code works in a cloud sandbox where it can also run the project's tests, and your pull request comes from your own GitHub account.

Advanced: run the agent on your own computer

You need Node.js and Claude Code (or Codex CLI or Gemini CLI). Then run:

npx lendmyai

The first time, this signs you in to GitHub. It then opens the app in your browser. Pick a task and click Claim & run agent, and watch progress live. Review the changes and the handoff note, then choose one of:

ActionWhat it does
Open pull requestThe owner reviews it
CheckpointPush the work so far, so anyone (with any AI) can continue it
Keep claimContinue later
ReleaseGive the task up
You can hold one task at a time. Claims expire after 24 hours.
