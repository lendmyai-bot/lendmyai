Command line

Run the agent on your own computer with the lendmyai CLI.

Install nothing: run it with npx lendmyai. You need Node.js and an AI CLI such as Claude Code.

lendmyai                          sign in if needed, open the app
lendmyai tasks [owner/repo]       list open tasks
lendmyai work <owner/repo#123>    claim and run your agent in the terminal
lendmyai auto [owner/repo]        work on several open tasks at once
lendmyai release <owner/repo#123> give up a claim
lendmyai init <owner/repo>        create the label and list the repo
lendmyai login | logout

Work on several tasks at once

For advanced users: open a terminal, run one command, and your AI picks up the tasks nobody is working on, including ones a previous contributor handed off.

npx lendmyai auto --parallel 3
OptionWhat it does
[owner/repo]Only look at one project (default: all projects)
--parallel <n>Tasks to work on at the same time (default 2, max 5)
--max <n>Stop after this many tasks (default 5)
--dry-runOnly list the tasks that would be picked up
--agent, --agent-cmdChoose the AI CLI, as with work
--yesSkip the confirmation

Each task runs unattended in its own checkout, with edits only and no shell approvals. When a run ends, finished work becomes a pull request, partial work is checkpointed for the next contributor, and a run that changed nothing releases the task. Output for each task is saved in ~/.lendmyai/logs. Press Ctrl+C to stop and release the tasks still running.

Claims expire after 24 hours. Batch mode lifts the one-task-at-a-time limit, so use a number you can review.
